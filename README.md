
# CS430 Assignment 3 – SLCM Classification Analysis

## Project Description
This assignment uses machine learning to predict whether a household has $3,000 or more in overdue rent.

## Dataset
SLCM Rent Arrears Dataset

## Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Classifier (SVC)

## Results
KNN had the highest F1 score (0.423) and recall (37.6%) among the five original models.
